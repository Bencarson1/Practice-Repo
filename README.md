## NebedaHub

NebedaHub is four apps on one database: NebedaHub for customers (design, order, pay for and track bespoke outfits), NebedaHub Business for tailors, NebedaHub Seller for fabric sellers and NebedaHub Admin for the platform team.
The first shop using it is Nebeda Threads.
See [`wearvia/README.md`](wearvia/README.md) for how to run it, and [`WEARVIA-SPEC.md`](WEARVIA-SPEC.md) for the full specification.
